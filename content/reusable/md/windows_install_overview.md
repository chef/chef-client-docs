You can install Chef Infra Client on Windows machines in the following ways:

- Bootstrap Chef Infra Client using [knife bootstrap](https://docs.chef.io/workstation/latest/tools/knife/knife_bootstrap/) from a local workstation using WinRM.
- Download Chef Infra Client to the target node, then run the Microsoft Installer Package (MSI) locally.
- Use an existing Windows management tool, such as System Center.
